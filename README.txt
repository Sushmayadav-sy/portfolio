SUSHMA PORTFOLIO — QUICK START\n\n1. Extract the ZIP (do not open index.html from inside the ZIP).\n2. Double-click index.html in the extracted folder.\n3. To add your picture: copy your JPG into images and name it my-photo.jpg. The photo automatically replaces the SY placeholder.\n4. Keep index.html, styles.css, script.js and images together.\n5. For GitHub Pages: upload these files and the images folder to a GitHub repository. Go to Settings > Pages > Deploy from a branch > main > /(root) > Save.\n\nNo coding tools or build process required. Google Fonts require an internet connection; fallback fonts are included.\n
